# Domain Maps

## Purpose

This directory contains documentation about domain-specific translation guidance in the Linguitect ecosystem. These maps provide specialized strategies for translating code in specific application domains, addressing the unique patterns, libraries, and idioms common in those domains.

## Contents

- **data-processing.md**: Translation strategies for data processing applications
- **web-development.md**: Translation strategies for web development
- **numerical-computing.md**: Translation strategies for numerical and scientific computing

## Usage Guidelines for LLM Agents

1. Use these maps when translating code in specific application domains
2. Identify the domain of the source code and consult the appropriate map
3. Apply the domain-specific strategies with consideration for language capabilities
4. Combine with paradigm and pattern maps for comprehensive translation

Different application domains often have specialized libraries, frameworks, and idioms that require specific translation approaches. These maps focus on preserving domain semantics while adapting to the target language's ecosystem and best practices for that domain.
