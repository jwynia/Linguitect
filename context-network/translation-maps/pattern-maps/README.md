# Pattern Maps

## Purpose

This directory contains documentation about design pattern implementations across different programming languages. These maps provide guidance for translating common design patterns while maintaining their intent and benefits in the target language.

## Contents

- **iterator-patterns.md**: Iterator implementation patterns across languages
- **builder-patterns.md**: Builder pattern implementations across languages
- **observer-patterns.md**: Observer pattern implementations across languages

## Usage Guidelines for LLM Agents

1. Use these maps when translating code that implements common design patterns
2. Identify the pattern in the source code and consult the appropriate map
3. Apply the target language implementation with consideration for language idioms
4. Combine with paradigm maps when the pattern crosses paradigm boundaries

Design patterns represent proven solutions to common programming problems, but their implementations vary significantly across languages. These maps focus on preserving the intent and benefits of each pattern while adapting to the idioms and capabilities of the target language.
