# Paradigm Maps

## Purpose

This directory contains documentation about cross-paradigm translation strategies in the Linguitect ecosystem. These maps provide guidance for translating code between different programming paradigms, such as object-oriented, functional, and procedural.

## Contents

- **oop-to-functional.md**: Strategies for translating object-oriented code to functional paradigms
- **procedural-to-oop.md**: Strategies for translating procedural code to object-oriented paradigms
- **functional-to-oop.md**: Strategies for translating functional code to object-oriented paradigms

## Usage Guidelines for LLM Agents

1. Use these maps when translating between languages with different paradigm emphases
2. Start with the appropriate map based on the source and target paradigms
3. Apply the strategies with consideration for language-specific features
4. Combine with pattern maps for specific implementation patterns

Paradigm bridging is one of the most challenging aspects of code translation, as it often requires fundamental restructuring of code organization and thinking. These maps provide structured approaches to this challenge, focusing on preserving semantic intent while adapting to the target paradigm's strengths.
