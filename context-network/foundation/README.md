# Foundation

## Purpose

The Foundation directory contains core reference documents that explain the fundamental concepts, architecture, and design principles of Linguitect. These documents serve as the foundation for understanding the entire Linguitect ecosystem.

## Contents

- **linguitect-core.md**: Core concepts and principles of the Linguitect intermediate representation language
- **architecture.md**: System architecture and component relationships
- **design-principles.md**: Guiding design philosophy and rationale
- **terminology.md**: Glossary of key terms used throughout the project
- **metadata-schema.md**: Documentation structure and metadata standards

## Usage Guidelines for LLM Agents

1. Start with linguitect-core.md to understand the fundamental purpose and concepts
2. Explore architecture.md to understand how components interact
3. Review design-principles.md to understand the reasoning behind design decisions
4. Reference terminology.md when encountering unfamiliar terms
5. Consult metadata-schema.md to understand the documentation structure

These foundation documents should be considered relatively stable and authoritative, changing only with significant evolution of the Linguitect project.
