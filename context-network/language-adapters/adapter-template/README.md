# Adapter Template

## Purpose

This directory contains template documents for creating new language adapters in the Linguitect ecosystem. These templates provide a standardized structure and guidance for documenting the mapping between specific programming languages and the Linguitect intermediate representation.

## Contents

- **adapter-structure.md**: Template for overall adapter structure and organization
- **import-adapter.md**: Template for import adapters (language to Linguitect)
- **export-adapter.md**: Template for export adapters (Linguitect to language)

## Usage Guidelines for LLM Agents

1. Use these templates when creating documentation for new language adapters
2. Follow the structure and format to ensure consistency across adapters
3. Customize the templates to address language-specific features and idioms
4. Ensure all required sections are completed with appropriate detail

When creating a new language adapter, start by copying these templates to a new language-specific directory, then customize them for the target language while maintaining the overall structure.
